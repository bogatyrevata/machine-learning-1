# machine-learning-1

## Запуск проекта

````bash
git clone https://github.com/bogatyrevata/machine-learning-1.git
cd machine-learning-1

python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
````

## Cómo ejecutar

Requiere Python 3.11 o superior (desarrollado con Python 3.14).
